# Release notes for pkpdutils 2.0.0

The figures are charts of sbmlsim-core instead of matplotlib figures, which makes this a major release.

- Every plot function returns a `sbmlsim_core.chart.Chart` instead of a matplotlib `Figure`; `draw_nca_panel` returns the `ChartPlot` instead of the `Axes`. A chart is saved by the suffix of its path, `chart.save("figure.svg")` (SVG, the default everywhere; PNG with `dpi=`; the JSON of its spec), and shows itself in a notebook.
- `ax=` and `axes=` are gone. Every function takes `chart=None, row=0, column=0` instead: without a chart it draws one of its own, with one it draws its panels into the cells of that chart from `(row, column)` on (`plot_nca` two cells along the row and a third for the parameter table, `plot_fit` two down the column, `plot_mean_timecourse` and `plot_timecourse(facet=...)` one per panel along the row, `plot_study_curves` two rows, `plot_nca_grid` one cell per sample). `new_chart(width, height, rows=, columns=)` gives a chart of the package (size in inches, matplotlib's font sizes) to lay several figures out in.
- `save_figure(chart, path, formats=, dpi=)` writes `svg` (default), `png` and `json`; `pdf`, `tif`, `jpg` and `eps` and the `transparent` and `**kwargs` of `savefig` are gone.
- `Report.add_figure(chart, caption, heading=)` renders the chart to SVG (the `dpi` argument is gone); `write_html` embeds base64 SVG, `write_markdown` writes `<stem>_<n>.svg`.
- `PlotStyle`: `data_marker` and `terminal_marker` are markers of `sbmlsim_core.chart.MARKERS` (`circle`, `square`; matplotlib's codes `o`, `s`, ... are still read), `annotation_fontsize` is a size in points (6.94, matplotlib's `x-small`), `cmap` a colour map of `sbmlsim_core.COLOR_SCALES` (the sequential and diverging maps of matplotlib).
- `pkpdutils.plot` no longer exports matplotlib helpers; `_common` holds the chart helpers (`chart_of`, `value_axis`, `plain_log_ticks`, `data_limits`, `Frame`, `legend_room`, `row_axis`, ...).
- python >= 3.14.
