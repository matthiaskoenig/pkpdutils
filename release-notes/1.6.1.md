# Release notes for pkpdutils 1.6.1

## Fixes

- The floor of the rust kernel is `pkpdutils-core>=0.5.1`, whose macOS wheel links no mimalloc. The kernel wheels of 0.4.0 to 0.5.0 set mimalloc as the allocator of the extension on every platform, and on macOS mimalloc keeps the heap of a thread in two slots of the pthread TLS block which it claims by compiled in number. Two extension modules which each link a copy therefore own the same two slots and allocate out of each other's thread heaps without a lock, which corrupts them, so an installation of `pkpdutils` on macOS next to another package whose extension links mimalloc could fail in any way at all. The release notes of `pkpdutils-core` 0.5.1 carry the details and `pkpdutils_core.__allocator__` reports which allocator a wheel links. Nothing of `pkpdutils` itself changes and the numerics of the kernel are those of 0.5.0.
