# Release notes for pkpdutils 1.7.1

## Fixes

- The floor of the rust kernel is `pkpdutils-core>=0.7.0,<0.8`. Release 1.7.0 still required `pkpdutils-core>=0.6.0,<0.7`, so an installation of `pkpdutils` could not resolve the kernel 0.7.0, the wasm host and the npm package of the kernel, whose python half is 0.6.0 with one test more. Nothing of `pkpdutils` itself changes, the suite and the differential gate of the two engines pass against 0.7.0.

## Documentation

- The performance page measures the rust kernel 0.7.0 against the python core on ten batch shapes with 15 repeats per engine and keeps the raw samples, the interquartile ranges, the dependency versions and the phase timings. On the dense batch of 10 000 profiles the kernel is 25.27 times faster with automatic workers and 5.37 times with one worker per engine. A profile of the analysis separates the phases and the functions and names the result construction and the duplicate decoding of the input as the remaining costs.
