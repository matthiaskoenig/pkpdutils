# Release notes for pkpdutils 1.6.0

## Fixes

- `nca_urine` with a plasma curve whose area is exactly 0 raised `ZeroDivisionError`. The renal clearance is now `inf` for a recovered amount over an area of 0 and `NaN` for 0 over 0, which is what the kernel answers as well.
- `nca_sparse` and `nca_urine` take the python path when the kernel refuses a request as unsupported, for instance a unit which the registry of the kernel does not read, instead of raising. A request the kernel rejects as malformed still raises `ValueError`.
