# Release notes for pkpdutils 2.0.1

## Fixes

- The caps of the error bars are as long as in the matplotlib figures of 1.x again. The figures set the `error_cap` of `sbmlsim_core.chart` to matplotlib's `capsize`, which sbmlsim-core reads as such from 0.37.0 on (a cap twice that long), so with 0.34.0 they were drawn half as long. The floor is `sbmlsim-core>=0.37.0`, and the images of the documentation are drawn again.
