# CLAUDE.md

This file provides guidance when working with code in this repository.

## Project

`pkpdutils` is a python library for the pharmacokinetic and pharmacodynamic analysis of timecourses and parameters: non-compartmental analysis, uncertainty propagation, curve fitting, statistics on parameters (tests, bioequivalence, drug-drug interactions, meta-analysis) and figures. Pure library, no CLI entry points. Requires python >= 3.13, packaged with hatchling (version is read from `src/pkpdutils/__init__.py`). Runtime dependencies are `numpy`, `scipy`, `pandas`, `xarray`, `pint`, `pydantic`, `matplotlib` and `rich`. It was `pkdb_analysis` until 0.3.1; the design of the rewrite is in `docs/superpowers/specs/2026-09-14-pkpdutils-redesign-design.md`.

`develop` is the default branch and takes every change through a pull request; direct pushes are rejected by the rulesets in `.github/rulesets/` (applied with `.github/rulesets/apply.sh`), which require the `tests`, `ruff`, `ty` and `docs` checks. `main` only tracks the latest release and is fast-forwarded by the `sync-main` job of the release workflow, never by hand.

Release steps are in `docs/development.md`: the release is prepared on a branch, `uvx bump-my-version bump [dev|major|minor|patch]` updates `src/pkpdutils/__init__.py` and `CITATION.cff` and commits without tagging, and the tag is created on `develop` after the pull request was merged, which triggers the PyPI release workflow. A development version is finalized with `uvx bump-my-version bump dev` (`1.0.0.dev0` becomes `1.0.0`), while `major|minor|patch` start the next development cycle.

Documentation is [Zensical](https://zensical.org/): markdown sources in `docs/`, configured in `zensical.toml`, built into the gitignored `site/`. The API reference is rendered from the docstrings by mkdocstrings; a page in `docs/api/` is just `::: pkpdutils.<module>`. Formulas use `pymdownx.arithmatex` with MathJax. `scripts/llms_txt.py` runs after the build and writes `llms.txt`, `llms-full.txt` and the markdown of every page into `site/`. `scripts/render_examples.py` runs every example of `tests/examples/test_examples.py` in a temporary directory and copies its figures into the committed `docs/images/`, which the pages embed and `docs/gallery.md` shows as one card per example; run it after an example or a plot function changed. `scripts/benchmark.py [case]` times the hot paths (`nca-small`, `nca-large`, `nca-multiple`, `bootstrap`, `delta`, `fit`, `constructors`, `iterate`, `all`), every case in a fresh interpreter, and prints a markdown table of size, median wall time and peak resident set size; `docs/development.md` documents all three scripts and the convention that every snippet of the documentation runs from the root of the repository under `python -W error`.

## Architecture

**`units.py`.** One pint `UnitRegistry` per process, `ureg`; `Q_` creates quantities, `Quantity` and `Unit` are the annotation types. `check_dose_unit` validates dose units, `normalize_volume` and `normalize_clearance` convert results to `liter`/`liter/kg` and `liter/hour`/`liter/hour/kg`. Numerics run on plain arrays in the units of the input, pint is used at the boundaries.

**`timecourse.py`.** `Timecourse` is one curve (pydantic, frozen): `time`, `value`, units, optional `sd`/`se`/`n`, a `Dosing` protocol and metadata. `Dosing` (pydantic, frozen) is the dosing protocol of a curve: `amounts`, `times`, `durations` (`None` unless `Route.IV_INFUSION`), one `unit`, one `route`; sorted by time on construction; constructors `Dosing.single(dose)`, `Dosing.from_doses(doses)`, `Dosing.regimen(dose, interval, n_doses)`; properties `n_doses`, `doses`, `first`, `last`, `intervals`, `tau` (the common interval, `None` if irregular or single dose), `is_regular`, `total_amount`, `shifted(offset)`. `Timecourse.dosing` is the field; the constructor also accepts a single `dose: Dose` keyword (converted to a protocol of one dose, giving both raises); `Timecourse.dose` is a read-only property returning the first dose; `relative_to_dose(which="first" | "last")` shifts the curve and its protocol, `to_batch(dim, label)` wraps it as a `Timecourses` of one sample. `DosingRegimen(dose, interval, n_doses).dosing()` is a convenience constructor of a regular `Dosing`, no longer an `NCAOptions` field. `Timecourses` wraps an `xarray.Dataset` with a `time` dimension plus any sample dimensions, the variables `value` and optionally `sd`, `se`, `n`, `nominal_time` (the scheduled time of every point, `from_arrays(nominal_time=)`/`from_dataframe(nominal_time=)`, read by `nominal_times` and shifted by `relative_to_dose`), the protocol as `dose_amount`/`dose_time`/`dose_duration` over `(*sample_dims, "dose_index")` (`NaN` padded, the doses at the front of the row) and units in `attrs["units"]`; `times` and `values` return the `(samples..., time)` arrays every analysis works on; `n_doses`, `n_dose`, `first_dose_*`, `last_dose_*` and `dosing_of(**indexers)` read the protocol of a batch back; `relative_to_dose(which)` shifts every sample by its own dose time (the shared grid for equal shifts, the union grid otherwise). Sample labels keep their dtype in `from_timecourses` and `from_dataframe`. `select(**indexers)` cuts a batch by labels, lists or slices of a sample dimension or of a coordinate along one, `groupby(coord)` walks the groups of a coordinate, `mean(dim, *, spread, min_n)` reduces a sample dimension to the group curve with `sd`, `se` and the count `n` of every time point (so `se = sd / sqrt(n)` holds on a ragged group as well; `n_subjects` is the largest count, the number of subjects of a sample, whether the batch keeps `n` per sample or per time point) and `dose_normalized(reference=None)` divides the values by the dose. `from_arrays` takes `dose=` as a `Dose`, a `Dosing` or a mapping (`amount`, `unit`, optionally `time` and `duration`, one dose or one protocol per sample, `route=` separately) and `coords=` carries the non-dimension coordinates (`period`, `sequence`, a covariate) which travel into every result. The substance and the route are batch-level attributes when every sample shares one (`substance`, `route`) and coordinates along a sample dimension when they differ (`SUBSTANCE_VAR`, `ROUTE_VAR`): `substances` and `routes` return the per-sample arrays and are `None` for a uniform batch, while `substance`/`route` raise for a mixed one; `from_timecourses` builds the coordinates from curves which differ and `dose_mapping(..., allow_mixed_routes=True)` lets the protocols through.

**`result.py`.** `ParameterResult` is the shared container of `NCAResult` and `FitResult`: an `xarray.Dataset` over the sample dimensions with `attrs["units"]` per variable and the integer `flags`, the classification of the variables (`parameters`, `derived_variables`, `statistics` of `statistic_variables`, `point_variables`, with the suffixes of `base_name`), `to_quantities`, `to_dataframe` (one row per sample, point variables excluded), `flag_table` and `summarize(dim)` (mean, `x_sd`, `x_se`, `x_cv`, the t interval, the quartiles, `x_min`, `x_max`, `x_n` and the geometric statistics, the `interval_*` point variables reduced over `dim` as well). `summary_table(result, dim, *, by, parameters, stats, digits, units, layout)` (also a method) formats those numbers into the parameter table of a publication: one row per parameter and group, every cell a string of `digits` significant digits, `TABLE_STATISTICS` the statistics it knows and `DEFAULT_STATISTICS` the ones it writes without being asked. `to_units(units)` converts named variables of a result with pint, together with the variables derived from them (the uncertainty and summary companions and the dose normalized `x_dn`, whose dose stays; the dimensionless `x_cv`, `x_geocv`, `x_n` are left alone) and rewrites `attrs["units"]`; `dose_normalized_names` is the hook for a parameter whose normalized variable is not `x_dn` (`auc_inf_obs` is `auc_inf_dn`).

**`report.py`.** The study report: `Report` (a title and a list of sections, `add_text`, `add_table(frame, caption)`, `add_figure(fig, caption, dpi=150)` which renders the figure to PNG right away, `write_html` self-contained with base64 figures and `write_markdown` with the figures as files next to it, every cell formatted with `result.format_number`) and `study_report(batch, result, *, dim, by=None, options=None)`, which assembles the package of ICH M13A 2.2.2: `methods_line`, the summary table with `M13A_STATISTICS`, `acceptability_table`, the parameters per subject, `plot_mean_timecourse` and `plot_nca_grid`. `matplotlib` is imported inside `study_report`, so `import pkpdutils` stays free of it.

**`parallel.py`.** The worker pools of the package: `executor(kind, n_workers)` returns one lazily created, `atexit`-closed executor per kind (`"thread"`, `"process"`) and size, shared by every call of the process; `resolve_workers(n_workers, n_rows, threshold, max_workers=8)` turns the option into a worker count (`None` automatic and serial below the threshold, `1` serial) and `split_rows(n_rows, n_workers, min_rows, max_rows)` cuts the rows into about one contiguous slice per worker. The NCA runs its rows in threads (`NCA_WORKER_THRESHOLD`, 20 000 rows; the core is vectorized numpy and releases the GIL), the fit in processes (`FIT_WORKER_THRESHOLD`, 2 000 rows; a row is a python-heavy `least_squares` search and a pooled call needs the `if __name__ == "__main__":` guard). The process pool starts its workers with `PROCESS_START_METHOD` (`forkserver`, `spawn` on macOS and Windows) on every python version, never with the `fork` default of python 3.13, which may deadlock next to the threads of the NCA. A broken pool is dropped and replaced by the next `executor` call.

`__init__.py` re-exports `pkpdutils.io` and `pkpdutils.plot` as modules and carries the data model, the front ends, the options with their enumerations and the model library of the fit, so that a script imports from `pkpdutils` and `pkpdutils.plot` only. `console.py` (rich console for scripts and examples; `rich_table`/`print_table` render any data frame of the package as a rich table, and `ParameterResult.rich_table`/`__rich__` render a result as a table, transposed for a few samples, with short units via `pkpdutils.units.short_unit`; `summary_table(unit_style="short")` does the same for the publication table) and `log.py` provide the shared output/logging. Modules get their logger from the standard library with `logging.getLogger(__name__)`. The package never configures logging: `log.enable_rich_logging()` is the opt-in for scripts. Library code logs, it does not print, and log calls use lazy `%s` formatting rather than f-strings (enforced by ruff `G`).

**`nca/` - non-compartmental analysis.** `nca(timecourses, *, options)` flattens the sample dimensions to `(N, n_time)` arrays and runs `compute_parameters` (`nca/nca.py`), the pure numpy core: `auc.py` packs the valid points of every row to the front (`pack_valid`) and sums the trapezoid segments (`segment_areas`, linear / linear-up-log-down / log), `terminal.py` evaluates every candidate window of the terminal regression at once with suffix sums (`window_statistics`) and picks it by the `TerminalPhase` rule (best adjusted R², last n, all after tmax, manual); with `TerminalPhase.keep_candidates` it also returns the table of every candidate (`candidate_table`), which a single curve reports as the point variables `candidate_t_first`, `candidate_n_points` and `candidate_r2_adj` over the dimension `candidate`, `intervals.py` computes the parameters of every dosing interval of a multiple dose curve (`compute_intervals`, variables `interval_*` over the extra dimension `interval`), `steady_state.py` picks the last complete interval for the steady state parameters and drives the whole multiple dosing analysis (`compute_steady_state`) plus `superposition` and `accumulation_ratio` (a dataset with `accumulation_ratio` and `stationarity_ratio`); a last interval whose last sample falls short of its end by at most `NCAOptions.tau_tolerance` (0.1) is completed with the terminal regression (`complete_last_interval`, the variable `auc_tau_extrap_fraction`) instead of being flagged `INCOMPLETE_INTERVAL`. `tss.py` estimates the time to steady state from the per-interval troughs (`time_to_steady_state`, `TSSResult`, the monoexponential approach to the plateau and the stepwise linear trend test of PKNCA) and `bioavailability.py` the absolute and relative bioavailability of two results (`bioavailability`, the geometric mean ratio of the dose normalized exposures, `f_abs` or `f_rel` by the route of the reference). A batch with a protocol of more than one dose in any row, or with `NCAOptions.tau` set, is a multiple dose batch (`is_multiple_dose`): the point parameters (`cmax`, `tmax`, `clast`, the terminal phase, `cl`, `vz`, `mrt`, ...) are computed from the last dose on (`reference_dose(..., last=True)`), times relative to it; with one dose the reference dose is that dose and the analysis covers the whole curve. The terminal phase reports its window as `lambda_z_t_first`, `lambda_z_t_last` and `lambda_z_span` (the half-lives it covers, `(t_last - t_first) / thalf`); below `SPAN_MINIMUM` (2) the row is flagged `NCAFlag.SPAN_LOW`. `options.py` holds `NCAOptions` (`tau`, `tau_tolerance`, `intervals`), `TerminalPhase`, the enumerations and `NCAFlag` (`SPAN_LOW`: the terminal window covers fewer than two half-lives; `INCOMPLETE_INTERVAL`: the last interval is not covered by the data; `EXTRAPOLATED_TROUGH`: the trough of a bolus interval was regressed because the sample at the dose time carries the post-dose value); `result.py` holds `NCAResult` (an `xarray.Dataset` over the sample dims with `attrs["units"]` per variable and the integer `flags`, plus `has_intervals` and `intervals()` for the per-interval variables as a data frame) and `parameter_unit`, which derives the units with pint (`PARAMETER_UNITS` in `nca.py` maps every parameter to a unit expression). `nca_single` wraps one `Timecourse`. The rows run in chunks of `chunk_rows` over the thread pool of `pkpdutils.parallel` (`n_workers=None` automatic, `1` serial); the multiple dosing path is chunked the same way. `tests/nca/test_reference.py` reproduces `pkdb_analysis` 0.3.1 with `AUCMethod.LINEAR` and `TerminalMethod.ALL_AFTER_TMAX`. `uncertainty.py` propagates `sd`/`se` of group curves: `bootstrap` resamples every point (`resample_values`), runs `run_rows` on the `N*B` replicate rows and reduces them (`reduce_replicates`); `delta` perturbs every point once and propagates `se` through the numerical Jacobian; `NCAOptions.resolve_uncertainty` picks the bootstrap by default for group data. Variables `x_sd`, `x_se`, `x_ci_low`, `x_ci_high`, `x_geomean`, `x_geocv`, `n`; `NCAResult.summarize(dim)` gives the same layout for individual results; `partial_auc(timecourses, t_start, t_end, *, options)` (`nca.py`) is the area between two times, the variable `auc_partial`. `options` is keyword-only in `nca`, `nca_single`, `partial_auc` and `superposition`. A batch which carries a `route` coordinate is analysed per route: `row_routes` splits the batch and `run_rows` runs one group per route and merges them, so `c0`, `cl` against `cl_f`, `tlag` and the value at the dose follow the row (the fast path of one route is untouched); `NCAOptions.units` converts the finished result (`ParameterResult.to_units`). `nca/analytes.py` holds `metabolite_ratio(result, *, parent, metabolite, parameters, molar)`, the ratio of the exposures of two analytes of one result per subject, corrected by the molar masses when they are given.

**`nca/urine.py` and `nca/sparse.py` - urine and sparse designs.** `Excretion` (pydantic, frozen) is the urine study of one subject: the collection intervals `start`/`end`, the `volume` and either the `concentration` (in `unit / volume_unit`) or the `amount` of every collection, sorted and checked for overlap, with the properties `midpoint`, `rate`, `duration`, `cumulative` and `total_amount`. `nca_urine(excretion, *, options=None, plasma=None)` runs `compute_parameters` on the excretion rate curve (the rate at the midpoint of its interval, the convention of the Phoenix urine models 210 to 212) and renames its parameters (`RATE_PARAMETERS`: `cmax` to `max_rate`, `auc_last` to `aurc_last`, `tlast` to `mid_pt_last`, ...), adds `amount_recovered`, `percent_recovered`, `vol_ur` and, with the plasma curve or its result, `clr = amount / AUC` over the collection span; the rate curve travels as the point variables `rate`/`midpoint` over the dimension `collection`, and `parameter_unit` resolves the new placeholders `{amount}` and `{volume}`. `nca_sparse(times, values, *, design="serial" | "batch", options=None, time_unit, unit, dose=None)` is the destructive and batch design: the area of the mean curve with the linear trapezoid weights (`trapezoid_weights`, the estimator has to stay linear in the means), the variance and the Satterthwaite degrees of freedom from the per-animal identity of `bailer_variance`, which is Bailer 1988 and Nedelman & Jia 1995 for one sample per animal and carries the covariance of Holder 2001 for several; `sparse_mean` returns the mean curve with `sd`, `se` and `n` per time point as a `Timecourses` of one sample. Both front ends return an `NCAResult` without sample dimensions; the figures are `plot_excretion` and `plot_sparse` in `plot/nca.py`, the pages `docs/urine.md` and `docs/sparse.md`.

**`io.py` - exchange formats.** Readers `read_events`/`Timecourses.from_events` (NONMEM/Monolix event records: `EVID`/`AMT`/`DV`/`MDV`, `ADDL`/`II` expansion, `SS` steady state history, `RATE`/`TINF` infusion durations, Monolix column aliases, covariates as coordinates), `read_pknca`/`Timecourses.from_pknca` (the two PKNCA tables, joined on the subject), `read_adnca`/`Timecourses.from_adnca` (CDISC ADaM ADNCA, dose times recovered from `AFRLT - ARRLT`, `DTYPE == "COPY"` dropped); writer `write_events`/`Timecourses.to_events`. Every reader returns a `Timecourses` batch with one sample dimension, the observation times as given, one route and the protocol of every subject; a subject without a protocol gets a row of `NaN` dose entries (`_build_batch`, shared by all three readers, does not go through `Timecourse` since a subject may have no protocol at all). Writers `write_events`/`Timecourses.to_events`, `write_pknca`/`to_pknca` (the two tables, the inverse of `read_pknca`) and `write_adnca`/`to_adnca` (the ADNCA dataset, `ARRLT` and `DOSEA` from the reference dose of every record), so all three formats round trip. Every column keyword of a reader and of a writer ends in `_col` (`id_col`, `time_col`, `dv_col`, `amt_col`, `subject_col`, `conc_col`, ...) and all three readers take `covariates`. `analytes=` (with `analyte_col`, `param_col` for ADNCA) reads several analytes into one batch: every analyte is read on its own and the batches are stacked along the dimension `analyte` with the coordinate `substance` (`_stack_analytes`, `_read_analytes`); `read_adnca` also reads the infusion duration (`duration_col="ADUR"`) and the nominal time (`nominal_time_col="NRRLT"`, the variable `nominal_time`), both absent allowed, and `read_pknca` reads a `duration` column when the dose table has one. Columns are looked up case-insensitively; compartment columns (`CMT`/`ADM`) and modelled rates (`RATE -1`/`-2`) are out of scope and raise or are ignored.

**`cdisc.py` - the CDISC map.** `PKPARMCD` maps every variable of a result to its `PKPARMCD` code and `PKPARMCD_BY_ROUTE` the ones whose code depends on the route (`mrt`); both are read from `src/pkpdutils/data/pkparmcd.csv`, which was extracted from the NCI EVS package of the SDTM controlled terminology (codelist `C85839`) and whose header names the source, the date and the checksum, never transcribed by hand. `pkunit` writes a unit as `PKUNIT` spells it (`PKUNIT` the table of the spellings, `PKUNIT_SYMBOLS` the fallback per symbol), `to_pp(result, *, subject_dim, usubjid, spec, studyid, route, ppspec, digits)` lays a result out as the `PP` domain (one row per subject and parameter, `PPSCAT` from the analysis of the sample (`_steady_state_samples`) and from `STEADY_STATE_VARIABLES`, `PPSPEC` from `URINE_VARIABLES`, the fractions of `PERCENT_VARIABLES` as percentages, a variable without a code and a unit which is no `PKUNIT` value each named in one warning) and `write_pp` writes the csv; `spec="ADaM"` adds `PARAMCD`, `PARAM`, `AVAL` and `AVALU`.

**`fit/` - curve fitting.** `model.py` holds `Model` (`predict`, `derived`, `initial_guess`), `ModelParameter` (name, unit expression, bounds, whether it is positive) and `parameter_unit_expression`, which derives a parameter unit from `[x]` and `[y]` without any normalization, so a fit reports its parameters in the raw units of the data. `options.py` holds `FitOptions`, `Weighting`, `ParameterScale` and `FitFlag`; the model library is `models_exponential.py` (`MonoExp`, `BiExp`, `TriExp`, `Bateman`, curve stripping for the guesses), `models_response.py` (`Emax`, `SigmoidEmax`, `Imax`, `SigmoidImax`) and `models_linear.py` (`Linear`, `LogLinear`, `Power`, `Allometric`), re-exported by `models.py`. `engine.py` is the core: `fit_row` searches in the scaled space (`log10` for positive parameters) with `scipy.optimize.least_squares` from `n_starts` Latin hypercube starts, derives the covariance from the Jacobian, transforms the t intervals back, propagates the derived parameters with the delta method, computes the statistics (`aic`, `aicc`, `bic` with `K = k + 1` estimated parameters) and runs the residual bootstrap; `fit_rows` draws one seed per row and maps them over a `ProcessPoolExecutor` for `n_workers > 1`; `build_result` assembles the dataset. `result.py` holds `FitResult(ParameterResult)` with `predict`, `predict_all`, `correlation` and the `statistic_variables` (the goodness of fit and the counts, no parameters and not summarized); `frontends.py` has `fit_timecourse` (one curve, a result without a sample dimension), `fit_timecourses` (a batch, times relative to the dose) and `fit_table` (a variable against a coordinate along one dimension of any dataset); `compare.py` ranks models by AICc and the Akaike weights (`compare_models` also takes a `Timecourse` or a `Timecourses` in place of `x`/`y`); `proportionality.py` applies the confidence interval criterion of dose proportionality to a `Power` fit and returns a `ProportionalityResult` (`slope`, `ci_low`, `ci_high`, `bounds`, `proportional`, `inconclusive`, `dose_range`, `criterion`, `to_dict`), which `proportionality_table(result, *, digits)` formats as the table of a publication (one row per sample: the exponent with its interval, the acceptance bounds, the dose range and the verdict). The `p_cv` of a fit is a fraction, as every coefficient of variation of the package.

**`stats/` - statistics on parameters.** `sample.py` holds `ParameterSample` (individual values with `labels` and `coords`, or summary `mean`/`sd`/`n`, `geomean`/`geocv`; `log_moments` translates summary data with the log-normal relations), `Scale`, `Summary` and `summarize`; `ParameterResult.sample(name, dim, **indexers)` builds one from a result (the non-dimension coordinates of a batch travel through `nca` and `fit_timecourses` via the module-level `sample_coordinates`). `tests.py` has `compare` (scipy t, rank and permutation tests, Welch from moments for summary data, `TestResult` with the effect, its t interval, Cohen's d and Hedges' g), `multiple_comparison` (Holm, Bonferroni, BH) and `hodges_lehmann(a, b, *, paired=None, ci_level=0.90)` (the median of the Walsh averages or of the pairwise differences with the distribution free interval of the order statistics, the null distributions enumerated exactly up to `EXACT_MAX_N` values and approximated above, the p value of the matching rank test and the achieved coverage in `ci_level`; the `tmax` comparison of the EMA); `ratio.py` the geometric mean ratio with a t interval (paired by label or Welch) and `ratio_table`, the ratio table of a publication (one row per parameter, the ratio and its interval in percent, a `BEResult` adding the within-subject CV and the verdict); `bioequivalence.py` `tost` and `bioequivalence` (TOST; `Design` detected from the samples: `REPLICATE` from the sequences `TRTR`/`RTRT`, `TRT`/`RTR`, `TRRT`/`RTTR` as the fixed effects ANOVA of the log values with sequence, subject within sequence, period and formulation (EMA Method A, `BEParameter.anova`, `cv_intra_r`/`cv_intra_t` from the administrations of each formulation alone), 2x2 crossover from the `period`/`sequence` coordinates as the period-difference analysis of Chow & Liu, paired, parallel; `scaling="none"|"ema"|"fda"|"fda_nti"|"ema_nti"` applies the reference-scaled rules with `abel_limits` (widening above a `cv_intra_r` of 30 %, for the `scaled_parameters`, `("cmax",)` by default) and `rsabe_criterion` (whose point estimate is the subject-level difference the criterion is built on, not the effect of the ANOVA) and writes `scaled`, `limits_scaled`, `criterion`, `sd_ratio_upper`), `carryover_table`; `power.py` `power_tost` and `sample_size_tost` (the exact power of the two one-sided tests through Owen's Q by `scipy.integrate.quad`, the design constants of PowerTOST in `DESIGNS`, an odd `n` split into the two sequences it would really have, pinned to the published examples of PowerTOST in `tests/stats/test_power.py`); `ddi.py` `DDIThresholds` (FDA 2020 and EMA 2012, identical values) with `ddi_classification` (conservative bound of an interval, `uncertain`), `substrate_sensitivity(auc_ratio, *, thresholds=None)` and `ddi_table` (one row per parameter: the ratio with its 90 % interval, the class and its strength); `meta.py` `effect_size` (Hedges' g, mean difference, log ratio), `fixed_effect`, `random_effects` (DerSimonian-Laird), `heterogeneity`, `meta_analysis` over `Study` objects and `effects_from_arrays`. Results are frozen dataclasses. `tests/data/reference/meta_bcg.json` holds the BCG trials with the metafor results as the regression reference.

**`plot/` - figures.** `style.py` (`PlotStyle`, `dose_color`, `partial_color`), `timecourse.py` (`plot_timecourse` with `by`, `facet` and `max_legend`, `plot_mean_timecourse`: the mean of every group with its spread band, the individuals faint behind it, a linear and a semi-logarithmic panel and one legend, `plot_study_curves`: the four panels of a study report, the individuals on the actual times and the group means on the nominal times (`nominal_grid`, `on_nominal_times`), linear and semi-logarithmic), `nca.py` (`plot_nca` with a third panel listing the parameters with units and intervals, `plot_nca_grid` with one legend for the figure and the sample coordinates as panel titles, `draw_nca_panel` with error bars of the data, the confidence band of the terminal regression, the annotated peak, last point and half-life, shading `AUC(0-tau)` of a multiple dose result and, with `partial=` and `partial_range=`, a named partial area of `NCAOptions.partial_aucs` (`plot_nca(partial=)` and `plot_nca_grid(partial=)` read the interval from `NCAResult.partial_aucs` and shift it onto the panel), `plot_terminal_windows` of the candidate windows of the terminal regression (`TerminalPhase.keep_candidates`) against their start time with the chosen one marked, `plot_intervals` of the `interval_*` variables against the interval number, `plot_troughs` of `interval_ctrough`/`interval_cmin` per group against the interval end or number), `fit.py` (`plot_fit`, `plot_goodness_of_fit`, `plot_dose_proportionality`, `plot_bland_altman`), `parameters.py` (`plot_parameters`), `ratio.py` (`plot_ratio`), `meta.py` (`plot_forest`). `plot_ratio` and `plot_forest` write `estimate [low, high]` (and the weight of a study) in a column beside the rows; `plot_fit` and `plot_dose_proportionality` label their axes from `attrs["x_name"]`/`attrs["y_name"]`, which the front ends in `fit/frontends.py` set. A dose of a protocol of several doses is a dotted line and an infusion the shaded window from the dose time to its end (`draw_nca_panel` marks the dose it analyses alone, since the panel starts there). Every signature is `f(data, *, <options>, ax=None, style=DEFAULT_STYLE)`, `axes: Sequence[Axes] | None` for the multi-panel figures (`plot_nca`, `plot_nca_grid`, `plot_fit`, `plot_mean_timecourse`, `plot_timecourse(facet=...)`), a logarithmic axis is `log_x`/`log_y` (`plot_bland_altman` takes `log_ratio`, which selects the statistic) and every log axis carries plain tick labels; `_common.py` holds `figure_of`, `axes_of`, `plain_log_ticks`, `log_scale`, `sample_labels`, `sample_colors`, `group_colors`, `sample_title`, `format_value`, `dose_markers`, `estimate_text`, `unit_label`, `axis_label`, `group_order`, `annotation_room`, `make_room_right`, `legend_above_data` and `annotate_column`; `figure_of` and `axes_of` return the root figure of axes inside a subfigure. A unit of a result is labelled in the short symbols of pint (`mg/l` for `milligram / liter`) and a unit the data spells itself is kept as it is. Functions return the `Figure` and never show it; `draw_nca_panel` returns the `Axes` and is exported.

## Conventions

- Type checking is done with [ty](https://docs.astral.sh/ty/). `[tool.ty.terminal] error-on-warning = true` means warnings fail the check, so the tree must stay at zero diagnostics. Suppress a diagnostic with a rule-specific `# ty: ignore[rule-name]`, never a blanket `# type: ignore`. ty also runs as a pre-commit hook (`--extra dev`).
- Every module, class and function of the package carries full type annotations and a google style docstring (ruff `D`); `examples/`, `tests/` and `scripts/` are exempt from the docstring rules. Docstrings of parameters and methods carry the formula and a citation key of `docs/references.md`.
- Results are `xarray.Dataset` objects with one variable per parameter over the sample dimensions of the input and `attrs["units"]` on every variable.
- `examples/` at the top level holds the runnable examples, they are not part of the package and are run as modules (`python -m examples.timecourses`). An example writes into the current working directory and never opens a window; the `conftest.py` at the root selects the `Agg` backend for the test session. `tests/examples/test_examples.py` runs them.
- Library code does not call `plt.show()`; figures are returned or saved.
- Test fixtures live in `tests/data/`; `tests/data/reference/nca_reference.json` holds the results of `pkdb_analysis` 0.3.1 on them and is the regression reference of the NCA.
- `tests/data/validation/` holds the two public validation datasets (`theoph.csv`, `indometh.csv` of R `datasets`, the indomethacin profiles analysed both as a bolus and as a 0.25 h infusion), the published Phoenix WinNonlin and PKNCA results with their sources in `reference.json` and the `README.md` naming source and license; `tests/nca/test_validation.py` compares every parameter of every subject against them and `scripts/validation.py` writes the committed comparison table `docs/validation_table.md` and the table of `docs/validation.md`.
- `docs/workflows.md` holds the five walk-throughs from the data of a study to its table and figure (a study table, bioequivalence, drug-drug interaction, steady state, dose proportionality); `docs/data/study.csv` is the event table the quickstart of `docs/index.md` reads, the only data file a page may read.
- `tests/docs/test_snippets.py` executes every ` ```python ` fence of every page of `docs/` in the order it appears, one namespace per page, in a subprocess with warnings as errors and a temporary working directory with `docs/data/` next to it. A fence whose first line is `# not executed` is a fragment and is skipped. A number a page pastes as output has to come from a real run of that snippet.
- Markdown carries no hard line wraps: a paragraph, a list item or a table row is a single line. Code fences, headings and the rows of badges keep their line structure.
- Release notes go in `release-notes/` as part of a release commit.
