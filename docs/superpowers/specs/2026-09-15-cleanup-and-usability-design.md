# Cleanup and usability round

Date: 2026-09-15. Status: design of an autonomous improvement round (the maintainer asked for cleanup, bug fixes, performance, publication-ready examples and diagrams, with no interaction until finished). Three read-only surveys precede it: an API and bug audit (33 bugs, 44 inconsistencies), a performance profile, and a documentation audit against the tables and figures of pharmacokinetic publications. The surveys are session artifacts under `.superpowers/survey/` (gitignored); their findings are restated here where a decision depends on them.

## Decisions

| topic | decision |
| --- | --- |
| delivery | four pull requests into `develop`, each merged when its checks pass: A bug fixes and shared helpers, B performance, C API consistency and usability, D documentation, gallery and diagrams |
| breaking changes | allowed where consistency demands them (the API is pre-1.1); every one is listed in the section "Breaking changes" at the end and goes into the release notes of the next minor |
| version | unchanged (`1.0.1.dev0`); the maintainer sets the release version |

| CV convention | fractions everywhere: `FitResult` `p_cv` becomes a fraction (was percent); tables format percentages |
| `ci_level` defaults | 0.95 everywhere except `ratio`, `tost`, `bioequivalence` (0.90, the regulatory interval); documented in one place (statistics.md) |

| plot signatures | `f(data, *, <options>, ax=None, style=DEFAULT_STYLE)` everywhere; `log_x`/`log_y` everywhere (the `log` keyword is replaced); every log axis gets plain tick labels; multi-panel figures take `axes: Sequence[Axes] \| None` |
| io keywords | column names end in `_col` on all readers (`id_col`, `time_col`, `dv_col`, `amt_col`, ...), `covariates` on all three readers, reader errors are `ValueError` naming the subject |
| top-level exports | the enumerations needed to configure the options (`AUCMethod`, `Kind`, `TerminalMethod`, `BLQHandling`, `UncertaintyMethod`, `BootstrapSpread`, `BootstrapDistribution`, `NCAFlag`, `Weighting`, `ParameterScale`, `FitFlag`), the model library (`MonoExp`, `BiExp`, `TriExp`, `Bateman`, `Emax`, `SigmoidEmax`, `Imax`, `SigmoidImax`, `Linear`, `LogLinear`, `Power`, `Allometric`), `pkpdutils.plot` as a module, `summary_table` |
| names kept | `n` (subjects), `n_doses`, `n_dose`, `lambda_z_stderr`, `partial_auc` (its variable `auc_partial` gets a unit entry), `stats.summarize` and `ParameterResult.summarize` (documented as different things), `effect_size(control, treatment)` order (meta-analysis convention, documented) |

| memory | chunks are slices, not fancy-index copies; the bootstrap materializes replicates per chunk |

| terminal phase quality | `lambda_z_t_last`, `lambda_z_span = (lambda_z_t_last - lambda_z_t_first) / thalf`, flag `NCAFlag.SPAN_LOW` when the span is below 2 half-lives |

## A. Bug fixes and shared helpers

Every bug of the audit is fixed with a regression test built from its reproduction. The ones that define behaviour:

- `stats`: strings coerced to enumerations at the entry points (`compare`, `multiple_comparison`, `summarize`, `effect_size`, `meta_analysis`, `tost`, `bioequivalence`, `ddi_classification`); degenerate samples (no finite values, `n = 1`, zero variance, identical samples) give NaN statistics or a clear `ValueError` (no `ZeroDivisionError`, no escaping `RuntimeWarning`); `ParameterSample` rejects a negative `sd`; `PooledEffect.__eq__` compares (arrays with `np.array_equal`); the shared primitives (`welch_df`, `pooled_sd`, `cohen_d`, `exp_t_interval`, `paired_values`, `labels_match`, `log_positive`) live once in `stats/sample.py` as public functions.
- NCA: the delta method's `x_geocv` is the geometric CV over subjects (`sqrt(exp(sigma_log^2) - 1)` with `sigma_log` from `x_sd/x`), consistent with the bootstrap; a batch mixing single and multiple dose subjects analyses each row by its own protocol (a single dose row keeps `cl`/`cl_f`, a multiple dose row `cl_ss`/`cl_ss_f`); `summarize` respects `discrete_parameters` (no `_se`/`_ci` for counts and regression diagnostics); `TerminalMethod.LAST_N` honours `exclude_cmax`; a zero dose gives NaN dose dependent parameters (no new flag, a debug log); `Kind.EFFECT` applies `lloq`/`blq` like concentrations and documents that `auc_method` is linear for effects; `partial_auc` from a time before the first sample uses `C(0) = 0` for extravascular routes, the back-extrapolated `c0` for a bolus and NaN otherwise; `_take` and `decode_flags` exist once (`nca/auc.py`, `result.py`); the `repeat` helper of `bootstrap`/`delta` exists once.
- data model and io: `unit=""` is rejected with a message naming `"dimensionless"`; `tissue` survives the batch round trips (`attrs`); `write_events` writes `SD`, `SE`, `N` columns when present and `read_events` reads them (`sd_col`, `se_col`, `n_col`); a ragged batch round-trips through `to_dataframe`/`from_dataframe` (samples in the original order); the readers raise `ValueError` naming the subject for a single observation, duplicate times, a missing infusion duration, a NaN dose time (no pydantic dump); `route="oral"` strings are coerced everywhere; `IU` doses are accepted; a shared grid with NaN values stays shared through `to_events`/`from_events` (missing values are written as `MDV 1` rows and read back as NaN at their time).
- fit and plot: `plot_fit(log_x=True)` masks `x <= 0`; `plot_forest`/`plot_*(ax=...)` never touch the caller's layout engine; `plot_goodness_of_fit` draws a legend only with labels; log axes without positive values fall back to linear with a debug log; the `n_workers` docstrings say that a script needs the `if __name__ == "__main__"` guard with the `forkserver`/`spawn` start methods (python 3.14 default on linux) and `NCAOptions`/`FitOptions` docstrings repeat it.

## B. Performance

Measured on the survey machine (medians): `nca(N=100)` 4.3 ms, `nca(N=100 000)` 0.18 s serial, first pooled call 0.84 s; `Timecourse` x 10 000 0.63 s; `from_dataframe` 10 000 subjects 2.9 s; `from_events` 100 000 rows 2.1 s; iterating 10 000 curves 2.4 s; bootstrap 1 000 curves x 1 000 replicates peaks at 882 MB. Targets: small results 2x (pint caches), first pooled call no slower than serial, NCA core 1.9x at 8 threads, multiple dose batch 3x (chunking and the interval gather), bootstrap memory halved, `read_events` and `from_dataframe` 3x, iteration 3x. `scripts/benchmark.py` (committed) reproduces the numbers with `uv run python scripts/benchmark.py [case]` and prints a table; `docs/development.md` documents it.

Changes: `lru_cache` on the four pint helpers; a module `pkpdutils.parallel` with `executor(kind: "thread" | "process", n_workers)` (lazily created, reused, `atexit`-closed), `split_rows(n, n_workers, min_rows)` and the size threshold; `run_rows` uses threads and slices; `fit_rows` uses the process executor with `chunksize` and an initializer holding the model and the options; `reduce_replicates`, `summarize` and `replicate_statistics` compute the nan percentiles by sorting; the bootstrap materializes the replicates per chunk; `read_events` builds the per-subject arrays with `groupby`/`np.split` instead of scalar access; `from_dataframe` validates once per batch; `__iter__` builds the curves from the numpy arrays of the batch without `ds.isel`; `compute_intervals` gathers the interval block from the packed row once per row instead of re-packing per interval.

## C. API consistency and usability

The inconsistency table of the audit is applied as the decisions above say; in addition `Timecourses.from_timecourses` and `from_dataframe` agree on label types (the labels keep their dtype), `stats` results all have `to_dict`, collections `to_dataframe`, `ParameterSample.n` is `int | None`, `multiple_comparison` raises on an unknown method, `effects_from_arrays` defaults to `HEDGES_G` like the others, `proportionality_test` returns a `ProportionalityResult` dataclass (`slope`, `ci_low`, `ci_high`, `bounds`, `proportional`, `inconclusive`, `dose_range`, `to_dict`) and `plot_dose_proportionality` takes it.

New:

- `Timecourses.select(**indexers) -> Timecourses` (labels, lists or slices on any sample dimension or coordinate along it), `groupby(coord) -> Iterator[tuple[Any, Timecourses]]`, `mean(dim, *, spread="sd" | "se", min_n=1) -> Timecourses` (a group curve with `sd`/`se`/`n`; shared grid required, else the union grid with NaN), `dose_normalized(reference=None) -> Timecourses` (values per dose amount, unit `unit / dose_unit`), `relative_to_dose(which="first" | "last")`, `Timecourse.to_batch(dim="individual", label=None)`.
- `summary_table` in `result.py`: one row per parameter (and group when `by` is given), the statistics `n`, `mean`, `sd`, `cv`, `geomean`, `geocv`, `median`, `min`, `max`, `range` formatted with `digits` (significant digits) as strings, the unit in a column or in the header, `layout` `"parameters_rows"` (default), `"parameters_columns"`, `"long"`; `ParameterResult.summary_table(...)` delegates. `ParameterResult.summarize(dim)` adds `x_cv`, `x_min`, `x_max` and reduces the `interval_*` point variables over `dim` keeping the `interval` dimension.
- `stats.ratio_table(ratios | BEResult, *, digits=3, percent=True)`, `stats.ddi_table(test, reference, parameters, *, dim, thresholds, digits)`, `fit.proportionality_table(result, *, digits)`.
- NCA: `lambda_z_t_last`, `lambda_z_span`, `NCAFlag.SPAN_LOW` (`span < 2`).
- Plots: `plot_mean_timecourse(batch, *, by=None, spread="sd", individuals=True, individual_alpha=0.25, panels=("linear", "log"), axes=None, style)`, `plot_timecourse(..., by=, facet=, max_legend=12)`, `plot_troughs(result, *, by=None, spread="sd", x="time" | "interval", ax, style)`, `plot_nca_grid` legend once and titles `dose = 50 mg, individual = s1`, `plot_ratio(..., annotate=True, labels=None)`, `plot_forest(..., annotate=True)`, `plot_fit`/`plot_dose_proportionality` axis labels from `attrs["x_name"]`/`["y_name"]` set by the fit front ends, an infusion window in `plot_timecourse` and the NCA panel, shared helpers in `plot/_common.py` (`figure_of`, `axes_of`, `plain_log_ticks`, `sample_labels`, `sample_colors`).

## Breaking changes (for the release notes of the next minor)

- `options` is keyword-only in `nca`, `nca_single`, `partial_auc`, `superposition`.
- `FitResult` `p_cv` is a fraction (was a percentage).
- `plot_*`: `ax`/`axes` and `style` keyword-only, `log` replaced by `log_x`/`log_y`; `plot_dose_proportionality` takes a `ProportionalityResult`; `proportionality_test` returns a `ProportionalityResult`.
- `read_events`, `read_pknca`, `read_adnca`: column keywords renamed to `*_col`; `groups` of `read_pknca` renamed `covariates`.
- `Timecourses.n_workers`/`NCAOptions.n_workers` semantics: `None` is automatic, `1` serial.
- `stats`: `effects_from_arrays` defaults to `HEDGES_G`.
- Reader errors are `ValueError`, not pydantic `ValidationError`.
- `ParameterResult.summarize` no longer reports `_sd`, `_se`, `_ci_low`, `_ci_high`, `_geomean` and `_geocv` for the discrete parameters (`tmax`, `tlast`, `tau`, the counts and the diagnostics of the terminal regression); they keep `x`, `x_median`, `x_q25`, `x_q75` and `x_n`.
