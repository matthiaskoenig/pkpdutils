# Feature round after the tool survey: design

Source: `docs/superpowers/specs/2026-09-16-nca-tools-feature-survey.md`, section 4 (37 suggestions). This document fixes the decisions of every feature (names, signatures, defaults, semantics) so that the plan `docs/superpowers/plans/2026-09-16-nca-features.md` can implement them in eight pull requests into `develop`, each merged when its checks pass. Version stays `1.2.0.dev0`; the release is the maintainer's call. Every change of a default result is a breaking change and goes into the list at the end, which feeds the release notes.

## Decisions

| topic | decision |
| --- | --- |
| delivery | eight pull requests F1 to F8 in the order of the survey's section 4.6, each off the merged `develop` of the previous |
| defaults | the default results of an existing analysis do not change: every new rule is off by default or reproduces today's behaviour (`BLQHandling.NAN`, no acceptance thresholds, no partial AUCs, `C0Method.LOG_BACK_EXTRAPOLATION` with the same fallback), new variables are added, none renamed |
| names | CDISC names are a mapping (F6), not the variable names; variables keep the `pkpdutils` spelling (`clast_pred`, `auc_all`, `tlag`) |
| units | every new variable has an entry in `PARAMETER_UNITS`, a glossary row and, where a formula exists, a docstring with the formula and a citation key |
| tests | every feature has a closed-form or reference test; `tests/nca/test_reference.py` stays unchanged and passing; the docs snippets stay green (`tests/docs`) |
| dependencies | unchanged (`numpy`, `scipy`, `pandas`, `xarray`, `pint`, `pydantic`, `matplotlib`, `rich`); a mixed model is out of scope, the replicate designs use the fixed effects ANOVA (EMA Method A) |
| documentation | every feature is documented on its page with a runnable snippet; the pages `docs/nca.md`, `docs/bioequivalence.md`, `docs/formats.md`, `docs/plotting.md` grow sections; new pages `docs/validation.md`, `docs/urine.md`, `docs/sparse.md`, `docs/reporting.md` |

## F1. Parameters and BLQ rules (survey 1 to 7, 10)

- `tlag`: for an extravascular route, the time of the last sample before the first measurable value (finite and `> 0`) after the dose, relative to the dose; `NaN` when the first sample is measurable or the route is intravenous. Unit `{time}`, discrete parameter (no uncertainty in `summarize`).
- `auc_all`, `aumc_all`: the area (and moment) to the last observation of the row, including trailing zeros and values imputed by a BLQ rule; equal to `auc_last`/`aumc_last` when the last observation is positive. Units as `auc_last`/`aumc_last`.
- `clast_pred = exp(lambda_z_intercept - lambda_z * tlast)`, unit `{unit}`, `NaN` without a terminal phase; `auc_inf_pred` keeps using it.
- `auc_back_extrap_fraction`, `aumc_back_extrap_fraction`: for an intravenous bolus whose first sample is after the dose, the area (moment) of the segment from the dose (`c0`) to the first sample divided by `auc_inf_obs` (`aumc_inf`); 0 when the first sample is at the dose; `NaN` for other routes. Dimensionless.
- Dose normalization: variables `auc_last_dn`, `auc_all_dn`, `auc_tau_dn`, `cavg_dn`, `cmax_ss_dn`, `c0_dn` with unit `<unit of x> / ({dose})`, `NaN` without a positive dose (as `auc_inf_dn`); `NCAResult.dose_normalized(parameters: Sequence[str] | None = None) -> NCAResult` returns a copy carrying `x_dn` for the parameters given (every exposure and concentration parameter by default: those whose unit is `{unit}` or `({unit}) * ({time})`), derived from the dose amount of every sample.
- BLQ rules: new pydantic model `BLQRules` in `nca/options.py` with the actions `BLQAction` (`StrEnum`: `DROP`, `KEEP`, `ZERO`, `LLOQ`, `HALF_LLOQ`) or a `float` imputation; positional fields `first`, `middle`, `last` (before the first measurable value, between measurable values, after the last measurable value) or the alternative axis `before_tmax`, `after_tmax` (the two axes are mutually exclusive, validated); `terminal_regression: bool = False` says whether imputed points enter the terminal regression. `NCAOptions.blq: BLQHandling | BLQRules`; `BLQHandling.NAN` is `BLQRules(first=DROP, middle=DROP, last=DROP)` and `BLQHandling.ZERO_BEFORE_TMAX` is `BLQRules(before_tmax=ZERO, after_tmax=DROP)`, both kept. Presets: `BLQRules.ich_m13a()` (`first=ZERO, middle=DROP, last=ZERO`, imputed points excluded from the regression), `BLQRules.pkanalix()` (`before_tmax=ZERO, after_tmax=HALF_LLOQ`), `BLQRules.pumas()` (`first=KEEP, middle=DROP, last=KEEP`). `KEEP` keeps the measured value below the limit as it is. `BLQ_TRUNCATED` is set when any value of the row was dropped or imputed.
- Per-sample LLOQ: `Timecourse.lloq: float | None = None` (metadata), the batch carries it as the variable or coordinate `lloq` over the sample dims (the readers already write the coordinate); `nca` uses `NCAOptions.lloq` when set, else the per-sample `lloq` of the batch, else none.
- `C0` rule set: `bolus_c0` documents and implements the fallback chain (two points needed, both positive, declining, `t2 > t1`; else the first value), adds `C0Method.NONE` (no insertion, `c0` is `NaN` and the areas start at the first sample) and records which rule applied in the new integer variable `c0_method` (0 none, 1 back extrapolation, 2 first value). For an extravascular single dose the value at the dose time is 0 (already so) and for a steady state interval the minimum observed value of the interval (already so in `intervals.py`); the docstrings say so.
- Docs: `docs/nca.md` parameter table rows, a "BLQ rules" subsection with the presets and the three tools' conventions, the `C0` subsection; glossary rows; breaking changes: the per-sample `lloq` (see the list at the end), every new variable is additive.

## F2. Acceptance criteria, exclusions, named partial AUCs, per-sample windows, M13A tables, carryover (survey 8, 9, 11, 25, 26)

- `Acceptance` (pydantic, `nca/options.py`): `r2_adj_min: float | None = None`, `extrapolation_max: float | None = None` (fraction of `auc_inf_pred`), `span_min: float | None = None` (half-lives), `n_points_min: int | None = None`, `exclude: bool = False`; presets `Acceptance.pkanalix()` (0.98, 0.20, 3, 3). `NCAOptions.acceptance: Acceptance = Acceptance()`. The result carries the boolean variable `accepted` (`True` when no threshold is set or every set one is met) and the flag `NCAFlag.NOT_ACCEPTED = 2048`.
- Exclusion: the result carries the boolean variable `excluded` (all `False` by default; `True` where `acceptance.exclude` and not accepted). `NCAResult.exclude(mask=None, *, reason: str = "", **indexers) -> NCAResult` returns a copy with the samples marked (a boolean array over the sample dims, or indexers of one sample), `excluded_reason` a string variable. `ParameterResult.summarize`, `summary_table`, `sample`, `stats` entry points which read a result, `ratio_table`, `ddi_table` skip excluded samples by default (`include_excluded=False` keyword where a signature exists, documented once in `docs/nca.md`). `to_dataframe` keeps every row and the `excluded` column.
- Named partial AUCs: `NCAOptions.partial_aucs: Mapping[str, tuple[float, float]] = {}` (name to `(t_start, t_end)` relative to the first dose); `nca` computes them with the machinery of `partial_auc` and reports each as a variable with unit `({unit}) * ({time})`; an interval ending after `tlast` is completed with the terminal regression (`clast_pred * exp(-lambda_z (t - tlast))`) and the row is flagged `NCAFlag.PARTIAL_EXTRAPOLATED = 4096`; a name that collides with a result variable raises `ValueError`. `partial_auc` stays for the ad hoc call.
- Per-sample terminal windows: `TerminalPhase.windows: Mapping[Any, tuple[float, float]] | None = None`, keyed by the sample label (the label of a one-dimensional batch, a tuple of labels for several sample dims, the string `"*"` for the rest) to `(t_first, t_last)`; a sample with a window uses the points inside it (`MANUAL` with a time range), the others follow `method`. `NCAResult.terminal_windows() -> dict` returns the `(lambda_z_t_first, lambda_z_t_last)` of every sample in the same keyed form, so a reviewed analysis is re-run with `TerminalPhase(windows=result.terminal_windows())` identically (tested).
- M13A tables (`nca/report.py`): `M13A_STATISTICS = ("n", "geomean", "geocv", "median", "mean", "sd", "min", "max")` for `summary_table`; `acceptability_table(result, dim, *, threshold=0.8, share=0.2) -> tuple[pd.DataFrame, bool]`: one row per sample with `auc_last`, `auc_inf_obs`, their ratio and whether it is below `threshold`, and the verdict of the "below 80 % in more than 20 % of the observations" rule; `methods_line(options, result) -> str`: one sentence naming the trapezoid rule, the terminal phase rule and the range of the number of terminal points, for the methods section.
- Carryover: `stats.bioequivalence.carryover_table(batch, result, *, threshold=0.05) -> pd.DataFrame` with one row per sample carrying `predose` (the value at the dose time or the last one before it, `NaN` without one), `cmax`, `fraction` and `flagged` (`fraction > threshold`); `bioequivalence(..., carryover: Literal["ignore", "flag", "exclude"] = "ignore")` reads the pre-dose values when the test and reference results carry the batch (the front end takes the batches as optional keywords `test_batch=`, `reference_batch=`) and either flags the parameter rows (`BEParameter.carryover: tuple[str, ...]` of the flagged labels) or drops the flagged subjects from that parameter.
- Docs: `docs/nca.md` sections "Acceptance criteria and exclusions", "Partial areas", "Terminal windows per sample", "The tables of a regulatory report"; `docs/bioequivalence.md` "Carryover"; glossary rows; breaking changes: `NCAFlag` gains two members (additive).

## F4. Steady state completion and bioavailability (survey 14 to 20)

- `fluctuation_tau = (cmax_ss - ctrough) / cavg`, `swing_tau = (cmax_ss - ctrough) / ctrough`, `ptr = cmax_ss / ctrough` (peak-trough ratio), dimensionless, `NaN` without a trough.
- `thalf_eff`: effective half-life, the formula of PKNCA `pk.calc.thalf.eff` as its source reads (`log(2)*mrt`): `thalf_eff = ln 2 * MRT`, unit `{time}`, reported by every concentration analysis (single dose and multiple dose) beside `mrt`, whose infusion correction it carries. For a mono-exponential drug it is the terminal half-life. (The accumulation-ratio form `tau ln 2 / ln(R / (R - 1))` this section carried before is a different definition and is not what PKNCA computes; the two agree for a mono-exponential drug.)
- `auc_tau_extrap_fraction` and the recoverable interval: `NCAOptions.tau_tolerance: float = 0.1` (fraction of `tau`); when the last sample of the analysed interval falls short of `tau` by at most that, `auc_tau` is completed with the terminal regression from `tlast` to `tau`, `auc_tau_extrap_fraction = (auc_tau - auc_last_interval) / auc_tau` is reported, and the row is not flagged; beyond the tolerance the parameters stay `NaN` and `INCOMPLETE_INTERVAL` is set as today. `auc_tau_extrap_fraction` is 0 when nothing was extrapolated.
- Accumulation ratios: `accumulation_ratio_cmax_obs = cmax_ss / interval_cmax[0]`, `accumulation_ratio_cmin_obs`, `accumulation_ratio_ctrough_obs` from the first interval of the same curve (as `accumulation_ratio_obs`), `NaN` with one interval; `accumulation_ratio(steady_state, single_dose)` also returns `stationarity_ratio = auc_tau / auc_inf_obs` of the single dose.
- Time to steady state (`nca/tss.py`): `time_to_steady_state(result, *, method: Literal["monoexponential", "stepwise"] = "monoexponential", fraction: float = 0.9, alpha: float = 0.05) -> TSSResult` over the `interval_ctrough` (fallback `interval_cmin`) against `interval_start`: the monoexponential method fits `c_trough(t) = c_ss (1 - exp(-k t))` by least squares per sample and reports the time to reach `fraction` of `c_ss` (`-ln(1 - fraction) / k`); the stepwise method tests, interval by interval from the last one backwards, whether the linear trend of the remaining troughs is significant at `alpha` and reports the start of the first interval from which it is not (PKNCA `pk.tss.stepwise.linear`). `TSSResult` (frozen dataclass): `tss` per sample (an `xarray.DataArray` over the sample dims), `method`, `fraction`, `c_ss` (monoexponential), `to_dataframe()`.
- Bioavailability (`nca/bioavailability.py`): `bioavailability(test, reference, *, dim, parameter="auc_inf_obs", paired=None, ci_level=0.90) -> RatioResult` computes `f = (AUC_test / D_test) / (AUC_ref / D_ref)` per subject as the geometric mean ratio of the dose normalized exposures with its interval (`stats.ratio` on the `_dn` samples); `f_abs` when the reference is intravenous, `f_rel` otherwise, the name of the result says which.
- Route specific MRT: no rename; the CDISC map of F6 emits `MRTEVIFO`/`MRTIBIFO`/`MRTICIFO` by route.
- Docs: `docs/nca.md` "Steady state" rows and the "Time to steady state" subsection with `plot_troughs`; glossary rows.

## F5. Urine and sparse sampling (survey 12, 13, 34, 35)

- Excretion data (`nca/urine.py`): `Excretion` (pydantic, frozen): `start`, `end` (collection intervals, strictly increasing, non overlapping), `volume` (optional), `concentration` or `amount` (one of them, the other derived when the volume is given), `unit` (of the amount), `time_unit`, `volume_unit`, `dose: Dose | None`, `substance`, `label`; `Excretions` is out of scope, a batch is a list. `nca_urine(excretion, *, options=None, plasma: NCAResult | None = None) -> NCAResult`: the excretion rate `rate_k = amount_k / (end_k - start_k)` at the midpoint `mid_k`, the parameters `max_rate`, `tmax_rate`, `mid_pt_last`, `rate_last`, `aurc_last`, `aurc_all`, `aurc_inf_obs`, `aurc_inf_pred`, `lambda_z` and `thalf` from the log rate against the midpoint (the terminal machinery of `terminal.py`), `amount_recovered` (the sum), `percent_recovered` (of the dose), `vol_ur` (the total volume), and, with `plasma` (the result of the plasma curve of the same subject), `clr = amount_recovered / auc_last_plasma` over the collection span (the plasma `partial_auc` over `[first start, last end]`). Units through `PARAMETER_UNITS` with `{amount}` and `{volume}` placeholders.
- Sparse sampling (`nca/sparse.py`): `nca_sparse(times, values, *, design: Literal["serial", "batch"] = "serial", options=None, time_unit, unit, dose=None) -> NCAResult` where `values` is `(n_animals, n_time)` with `NaN` where an animal has no sample at a time: the mean curve with the Bailer estimator `AUC = sum_j w_j mean_j`, `V[AUC] = sum_j w_j^2 s_j^2 / n_j` (trapezoid weights `w_j` of the `options.auc_method` linear rule), the Nedelman and Jia degrees of freedom, the batch design covariance term of Holder when `design="batch"` (animals sampled at several times share a row), reporting `auc_last`, `auc_last_se`, `auc_last_df`, `auc_all`, `cmax`, `cmax_se`, `tmax`, and `n` per time point as the variable `n_points`; a `Timecourses` of the mean curve with `sd`, `se`, `n` per time point is returned by `sparse_mean(times, values)`. Requires equal `n` per time point only for the batch covariance, else the general formula. Nominal times are used.
- Figures: `plot_excretion(result, excretion, *, ax, style)` (the rate against the midpoint on a log axis with the regression, and the cumulative amount on a second axis), `plot_sparse(mean_curve, result, *, ax, style)` (the mean curve with the Bailer standard errors and the shaded `AUC`).
- Docs: `docs/urine.md`, `docs/sparse.md` (concepts, math with citations Bailer 1988, Nedelman 1995, Holder 2001, the Phoenix parameter names, runnable snippets with simulated data, figures rendered by new examples `examples/urine.py`, `examples/sparse.py`), nav entries after Uncertainty; glossary rows; `CLAUDE.md`.

## F6. Analytes, CDISC map, unit conversion, writers (survey 20 to 24)

- Analytes: a batch may carry the coordinate `substance` along a sample dimension (a study of parent and metabolite is a batch over `(analyte, individual)` with `substance` a coordinate of `analyte`); `Timecourses.substance` returns the one substance or raises when they vary (the coordinate is read then); `from_timecourses` builds the coordinate when the substances differ; the readers take `analytes: Sequence[str] | None = None` (`PARAMCD`/`ANALYTE` values to keep, giving the dimension `analyte`); `nca` runs per row as today; `metabolite_ratio(result, *, parent, metabolite, parameters=("auc_inf_obs", "cmax"), molar: Mapping[str, float] | None = None) -> pd.DataFrame` divides the metabolite by the parent per subject, corrected by molar masses when given.
- CDISC map (`pkpdutils/cdisc.py`): `PKPARMCD: dict[str, str]` mapping every result variable to its `PKPARMCD` code (`AUCLST`, `AUCIFO`, `AUCIFP`, `AUCPEO`, `AUCALL`, `CMAX`, `TMAX`, `CLST`, `TLST`, `C0`, `LAMZ`, `LAMZHL`, `LAMZNPT`, `LAMZLL`, `LAMZUL`, `LAMZSPN`, `R2ADJ`, `CLO`, `CLFO`, `VZO`, `VZFO`, `VSSO`, `MRTEVIFO`/`MRTIBIFO`/`MRTICIFO` by route, `AUCTAU`, `CMAX` and `CMIN` with `PPSCAT = STEADY STATE` for the steady state peak and minimum (there is no `CMAXSS`/`CMINSS` code), `CTROUGH`, `CAVG`, `FLUCP`, `SWING`, `ARAUC`, `ARCMAX`, `ARCMIN`, `ARCTROUG`, `AILAMZ`, `CLTAU`, `CLFTAU`, `TLAG`, `AUCPBEO`, `AUCINT` with the interval in `PPTEST`, `EFFHL`, `PTROUGHR`, `FABS`, `FREL`, `RENALCL`, `AURCLST`, `AURCALL`, `AURCIFO`, `RCAMINT`, `RCPCINT`, `ERMAX`, `ERTMAX`, `VOLPK`) parsed from the NCI EVS CDISC SDTM terminology package (the implementer fetches the current tab-delimited file once, keeps the codes and names of the variables the package reports in `src/pkpdutils/data/pkparmcd.csv` with the terminology version and date, never transcribes by hand; a variable without a code maps to `None` and the writer skips it with a warning); `to_pp(result, *, subject_dim, usubjid=None, spec="SDTM" | "ADaM") -> pd.DataFrame` lays the result out as the `PP` domain (`STUDYID` optional, `USUBJID`, `PPSEQ`, `PPTESTCD`, `PPTEST`, `PPCAT` the substance, `PPSCAT` (`SINGLE DOSE`/`STEADY STATE`), `PPORRES`, `PPORRESU`, `PPSTRESN`, `PPSTRESU`, `PPSPEC` (`PLASMA`/`URINE`), `PPRFTDTC` empty) with the units as `PKUNIT` spellings; `write_pp(result, path, ...)` writes the CSV. Units are converted to the CDISC spellings by a small table in the same module (`h*ng/mL`, `L/h`, ...).
- Unit conversion: `ParameterResult.to_units(units: Mapping[str, str]) -> Self` converts the named variables (and their `_sd`, `_se`, `_ci_*`, `_dn` companions) with pint and rewrites `attrs["units"]`; `NCAOptions.units: Mapping[str, str] | None = None` applies it to the result of `nca`; `docs/units.md` gets the section.
- Writers and routes: `write_pknca(batch, conc_path, dose_path, **cols)` and `write_adnca(batch, path, **cols)` as the inverse of the readers (round trip tests); a batch may carry the coordinate `route` along a sample dimension (a crossover with an intravenous reference and an oral test), `Timecourses.route` returns the one route or raises when they vary, `nca` reads the route per row (the parameters that depend on it, `c0`, `cl` against `cl_f`, `tlag`, follow the row), `from_timecourses` builds the coordinate; `read_adnca` reads an infusion duration column (`duration_col="ADUR"` by default, absent allowed).
- Docs: `docs/formats.md` sections "Analytes", "Writing PKNCA and ADNCA", "The PP domain"; `docs/units.md` "Converting a result"; glossary; breaking changes: `Timecourses.substance`/`.route` raise for a mixed batch (were single values).

## F7. Bioequivalence completion, tmax, power, report (survey 27 to 30, 32)

- Hodges-Lehmann (`stats/tests.py`): `hodges_lehmann(a, b, *, paired=None, ci_level=0.90) -> TestResult` with the estimate of the median difference (paired: Walsh averages of the differences; unpaired: the pairwise differences) and the distribution free interval (the exact order statistics of the Wilcoxon and Mann-Whitney null distributions below 50 pairs, the normal approximation above); the `TestResult` carries `effect`, `ci_low`, `ci_high`, `p_value` of the matching rank test; documented as the `tmax` comparison of EMA.
- Replicate designs (`stats/bioequivalence.py`): `Design` gains `REPLICATE` (the sequences `TRTR`/`RTRT`, `TRT`/`RTR`, `TRRT`/`RTTR` from the `sequence` coordinate, the periods from `period`); the analysis is the fixed effects ANOVA of the log values with sequence, subject within sequence, period and formulation (EMA Method A, ordinary least squares with numpy), reporting `gmr`, its 90 % interval from the residual variance, `cv_intra_r` from the reference replicates (the within-subject variance of the reference formulation alone) and `cv_intra_t` when the test is replicated; the ANOVA table is `BEParameter.anova` (a data frame). The mixed model (Method B, FDA) is out of scope and documented as such.
- Reference scaling (`stats/bioequivalence.py`): `bioequivalence(..., scaling: Literal["none", "ema", "fda"] = "none")`. EMA ABEL: for `cmax` only, when `cv_intra_r >= 30 %`, the limits widen to `exp(±k s_wr)` with `k = 0.760`, capped at `69.84 %` to `143.19 %` (`cv_intra_r` capped at 50 %), and the point estimate must lie within 80.00 to 125.00 %; AUC never widens. FDA RSABE: when `s_wr >= 0.294` (`cv_intra_r >= 30 %`), the criterion is the 95 % upper confidence bound of `(mu_T - mu_R)^2 - theta s_wr^2 <= 0` with `theta = (ln 1.25 / 0.25)^2` (Howe's approximation of the linearized criterion, as the FDA progesterone guidance) and the point estimate within 80.00 to 125.00 %; otherwise the unscaled analysis. NTI (`scaling="fda_nti"`): `sigma_w0 = 0.10`, the scaled criterion plus the unscaled 90 % interval within 80.00 to 125.00 % plus the variability comparison `s_wt / s_wr` upper 90 % bound `<= 2.5`; `scaling="ema_nti"`: limits 90.00 to 111.11 % for AUC (and `cmax` when named). `BEParameter` gains `scaled: bool`, `limits_scaled: tuple[float, float] | None`, `criterion: float | None` (the FDA bound). Every constant is cited (FDA progesterone guidance 2011, FDA warfarin NTI guidance, EMA 2010 4.1.10, ICH M13A appendix).
- Power and sample size (`stats/power.py`): `power_tost(*, cv, n, gmr=0.95, limits=(0.8, 1.25), design: Literal["2x2", "parallel", "2x2x4", "2x2x3"] = "2x2", alpha=0.05) -> float` with the exact power of the two one-sided tests through the bivariate noncentral t (Owen's Q, implemented by numerical integration with `scipy.integrate.quad` of the noncentral t density, as `PowerTOST::OwensQ`), the design constants of PowerTOST (`bk` and the degrees of freedom per design); `sample_size_tost(*, cv, gmr, target_power=0.8, design, alpha, limits) -> int` (the smallest even `n` for a crossover, any `n` for parallel, reaching the power). Validated against the published PowerTOST examples (`sampleN.TOST(CV=0.3, theta0=0.95)` gives 40 subjects at power 0.8158 for the 2x2 design, and the table of the PowerTOST vignette); documented on `docs/bioequivalence.md` "Sample size".
- Report (`report.py`): `Report` (a list of sections: a heading with text, a data frame or a figure) with `add_text`, `add_table(frame, caption)`, `add_figure(fig, caption, dpi=150)`, `write_html(path)` (self-contained: the figures embedded as base64 PNG, the tables as HTML tables with the same formatting as `summary_table`), `write_markdown(path)` (the figures as files next to it); `study_report(batch, result, *, dim, by=None, options=None) -> Report` assembles the M13A package: the methods line, the summary table with `M13A_STATISTICS`, the acceptability table, the parameter table per subject, the mean curves figure and the individual curves grid; documented on a new `docs/reporting.md` with the HTML of `examples/report.py` linked. No generated script.
- Docs: `docs/bioequivalence.md` sections "Replicate designs", "Reference scaled limits", "Narrow therapeutic index", "tmax", "Sample size"; `docs/reporting.md`; glossary; breaking changes: `Design` gains a member (additive), `BEParameter` gains fields (additive).

## F8. Figures (survey 33, 36, 37)

- `plot_terminal_windows(timecourse, result, *, ax=None, style=DEFAULT_STYLE, **indexers)`: the adjusted `R^2` of every candidate window against the start time of the window with the chosen window marked, next to the data with the fitted line; `terminal_fit` returns the candidate table (`TerminalFit.candidates: pd.DataFrame | None` with `start_time`, `n`, `r2_adj`, `slope`) when asked (`TerminalPhase.keep_candidates: bool = False`, and `nca_single` stores it in the result as the point variables `candidate_t_first`, `candidate_r2_adj` over the dimension `candidate`, only for a single curve).
- Partial AUC shading: `draw_nca_panel` shades a named partial area (`partial: str | None = None`, one of the `partial_aucs` of the result) in a third fill color `style.partial_color` with its value annotated, in addition to `AUC(0-tlast)`.
- The regulatory figure pair: `plot_study_curves(batch, *, by=None, nominal_times: ArrayLike | None = None, log_y_panels=True, axes=None, style)` returns the figure with the individual curves on actual times (linear and semi-logarithmic) and the mean curves per group on the nominal times (linear and semi-logarithmic), four panels, as ICH M13A 2.2.2.1 asks; when the batch carries a `nominal_time` variable it is used, else `nominal_times` maps every actual time to the nearest nominal one.
- Docs: `docs/plotting.md` sections; the gallery cards where an example gains a figure; breaking changes: none.

## Breaking changes (for the release notes of the next minor)

- F6: `Timecourses.substance` and `Timecourses.route` raise a `ValueError` for a batch whose samples differ (they were single attributes of the batch); the coordinates `substance`/`route` carry the values then.
- F2: `ParameterResult.summarize`, `summary_table`, `sample`, `ratio_table` and `ddi_table` skip excluded samples by default (`excluded` is all `False` unless `NCAResult.exclude` or `Acceptance(exclude=True)` marked samples, so existing results are unchanged).
- F2: every `NCAResult` carries the boolean variables `accepted` and `excluded`, so `NCAResult.to_dataframe` has two more columns (a third, `excluded_reason`, once a sample is excluded) between the parameters and the flags, and `BEResult.to_dataframe`/`to_dict` carry a `carryover` column; a reader which selects its columns is unaffected, one which reads them positionally is not.
- F4: an intravenous infusion whose first sample is after the dose starts at 0 at the dose time ("for extravascular and infusion single dose a concentration of zero is inserted at the dose time", Phoenix WinNonlin), where the analysis left an infusion curve as it was. Only the infusion half of that rule is taken: the areas of an extravascular curve still start at its first sample, since the other half would move the regression reference of `pkdb_analysis` 0.3.1. `auc_last`, `auc_all`, `aumc_last`, `auc_inf_obs`, `mrt`, `vss` and every partial area of such a curve gain the triangle from the dose to the first sample; a curve with a sample at the dose time and a steady state interval are unchanged. The WinNonlin infusion run of the indomethacin dataset is now part of the validation, which is what the change is measured against.
- F4: `accumulation_ratio(steady_state, single_dose)` returns an `xarray.Dataset` with the variables `accumulation_ratio` and `stationarity_ratio` instead of the `DataArray` of the accumulation ratio; `accumulation_ratio(ss, sd)["accumulation_ratio"]` is the array it returned before.
- F4: the last dosing interval of a profile whose last measurable sample falls short of the end of the interval by at most `NCAOptions.tau_tolerance` (0.1 of `tau`) is completed with the terminal regression instead of being given up, so such a profile reports the steady state parameters where it reported `NaN` and `NCAFlag.INCOMPLETE_INTERVAL` before. `tau_tolerance=0.0` restores the old behaviour.
- F4: the terminal regression of an intravenous infusion may not start at or before the end of the infusion (`t <= t_dose + dose_duration`), the rule of Phoenix WinNonlin; the samples taken during the infusion are no candidates of any window, so `lambda_z` and everything which reads it can change for an infusion curve which was sampled during the infusion. No other route is affected.
- F4: `tlag` is 0 rather than `NaN` for an extravascular curve whose first sample at or after the dose is already measurable, which is what Phoenix WinNonlin reports; `NaN` stays for an intravenous route and for a curve without a measurable value.
- F1: a batch which carries an `lloq` coordinate is analysed against that limit under the default options, where the analysis read only the scalar `NCAOptions.lloq` before; every batch of `read_adnca` with an `ALLOQ` column is one, and its `cmin`, `auc_last`, `tlast` and `flags` can change (the values below the limit are dropped, as `BLQHandling.NAN` says). Set `NCAOptions.blq` explicitly or drop the coordinate (`batch.ds.drop_vars("lloq")`) to keep the old numbers.
